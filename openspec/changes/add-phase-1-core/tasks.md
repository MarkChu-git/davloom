# Tasks

Every test that covers a scenario of this change's specs is named after it: its own name is the scenario's name, or the scenario's name followed by `:` and more, as in `Replacing a file: R2`. The requirement coverage check then finds it once the change is archived. Each task leaves `bun run check` and CI passing. A pull request that changes `packages/laws/LAWS.bend` waits for the owner's `laws-approved` label, and is opened only after the pull requests below it have merged (Decision 11 of design.md). Tasks 3.5, 5.2 and 7.1 change it, and task 2.2, which adds the approval check, needs the label as well.
